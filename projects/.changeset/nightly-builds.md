Nightly builds replace Canary releases. A nightly is an automatic build of the latest source, published under the `nightly` npm tag on days when the SDK changed, with a version such as `1000.0.0-nightly.57`. Nightly numbers only grow but can skip values. Like an RC, a nightly can include breaking changes, so install it with `--save-exact`, or `--exact` with Bun. The Canary versions were removed from npm, so they can no longer be installed
