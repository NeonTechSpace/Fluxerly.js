Fluxerly.js connects Node.js applications to Fluxer.
It supports sending messages, responding to events and building bots in JavaScript or TypeScript

{{release-status}}

## Start a bot

1. [Create a bot](/docs/{{version}}/create-a-bot/): Create the Fluxer application, store its token and invite the bot to a server
2. [Quick start](/docs/{{version}}/quick-start/): Install the SDK and make the bot answer !ping
3. [Build a small bot](/docs/{{version}}/small-bot/) with commands, an embed and a welcome message, or copy a complete [example bot](/docs/{{version}}/examples/)

The [core concepts](/docs/{{version}}/core-concepts/) explain the few ideas behind every guide. For an application that already uses Effect, start with [the Effect bot guide](/docs/{{version}}/effect-first-bot/)

## Run it in production

[Configuration](/docs/{{version}}/configuration/), [logging](/docs/{{version}}/logging/), [deploying](/docs/{{version}}/deploying/), [sharding](/docs/{{version}}/sharding/), [supervision](/docs/{{version}}/application-supervision/) and [testing](/docs/{{version}}/testing/) cover a bot that keeps running
